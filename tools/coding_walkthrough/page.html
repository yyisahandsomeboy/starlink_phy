01 / 控制头

知道了格式编号，也知道有多少“单位”；还不知道一个单位有多大。

第二个头部先经过卷积码译码、终止状态检查与重编码，再对拼接的信息字计算 CRC-8。下图是译码后的 128 个信息位，并非空口上按颜色直接分开的未编码字段。原来的四个卷积编码块各还包含 6 个终止输入位。

真实控制头 · 按接收顺序排列

16位前缀20位描述项填充最后8位CRC

本例第一项怎样解读

当前工作布局为 16 + 20D + padding + 8 = 128。每项先读 7 位编号，再读 1 位尚有语义歧义的位，再读 12 位数量；这些字段按 LSB 先行求值。这里第8位为0，7位与8位编号都等于66。CRC 的寄存器处理顺序则另按已验证约定执行。

length 目前解释为单位数量 C。C = 39 还不意味着已经知道39个什么码长的码字。“一单位一字”需要后续编码关系支持。

CRC能证明到哪里

CRC 一致支持这组头部位及其分组。它不会认证 MCS 参数表，也不会把格式编号自动翻译成 N、K、码率、Z 或星座位映射。20位布局仍保留已记录的字段语义限制。

已获得的观察此刻仍不能确定后面怎样约束
编号66，数量39Q、N、K、Z、H、G资源几何 + 调制 + 固定编码关系
头部结束于 r0=8875后续所有格式的官方含义有序分配假设；未知格式继续保留未知
CRC通过、头部重编码一致负载是否已译码、是否是业务明文负载单独进行LDPC与重调制检查

02 / 观测与候选长度

先把信号变成可检验的位假设。

接收机完成同步、FFT、均衡、跟踪，并去掉确定的 PN 四相旋转。下面的点是候选码字的真实接收观测，使用已有 FIT 导频增益归一化；没有对目标负载另拟合相位来迎合译码。理想点仅作为参照。

去 PN 后的 4,096 个接收点

蓝色为接收点；空心方框为理想16QAM点；橙色圆圈为下方所选资源。

一个资源 → 4个候选位

16QAM 有16个点，位数候选为 log₂16 = 4。串行标签也需要验证；本次胜出顺序是：

[ I<0, Q<0, |I|<2/√10, |Q|<2/√10 ]

LLR为0相对1的对数似然。正值偏向0，负值偏向1；绝对值越大，当前噪声模型下越有把握。这里展示原始数值计算的LLR，而非从屏幕像素反推。

Q = 4,096 最初是候选，最后由编码证据支持

几何、已知头部坐标和有序分配长度提供每单位资源数的候选表。对66，候选 Q=4096，于是 N=4Q=16384；K和Z仍未知。后来固定H在376字上成立，完整N与4位映射相互一致，才强化这一单位解释。没有把“39×4096看起来合适”当作唯一证据。

3,072个资源 / 12,288输入位1,024个资源 / 4,096奇偶位

上图是恢复模型后的分解，不是看星座点就能区分的信息/奇偶。两部分都可呈现16QAM。一个码字可以跨OFDM符号；序列已排除导频和DC，不能按1024列的外观直接划码字。

r0是接收机去掉导频/DC后的资源流序号。这里所有区间统一采用左闭右开 [start,end)。本例66直接接在CRC通过的头部后；第一帧66则还经过前置57的候选长度。

03 / 结构识别

突破来自一个可核对的线索，而非从“66”这个数字猜码率。

已有 Code 5独立恢复的1024条稀疏校验
→
公开置换族全部行支持集合精确吻合
→
有限候选搜索只用第2帧66的第1～8字
→
冻结胜出模型再做完整代数与译码检查

Code 5 的 H 与公开 AR4JA 置换族在采用 p0 删余的条件下，1024条行支持集合全部相同。这使我们有理由优先尝试这一族的其他大小、缩短方法和标签。CCSDS 131.0-B-5 第7.4节提供了数值置换表；标准并没有列出“Starlink MCS 66”，这里采用的p0删余策略也不同于标准通常写的末块p2删余。

真实筛选记录：候选越接近，原始硬判决越常满足校验

展示已保存的最佳候选前6名，并非完整直方图。每候选固定随机种子1991抽128条检查，作用在8字上，共1024次XOR检查；这里是译码前失败比例。0.25是研究筛选线，与受保护评价器门限无关。

搜索范围为131种母图/整块缩短候选 × 216种独立I/Q线性位标签 × 16种极性，共452,736种组合。只有一项低于0.25：148 / 1024 = 0.14453125。这个初筛只选出值得继续检验的假设，尚不能宣布FEC已恢复。

这一步实际做了什么：在公开结构族内识别一个接收等价模型；没有穷举任意LDPC，也没有只凭8个嘈杂码字直接拟合一个任意生成矩阵。失败候选在有限范围内被拒绝，不代表证明了全空间唯一性。

04 / 参数与循环结构

先从母图得到 H，再逐行确认 Z = 512。

操作传输坐标数的变化对输入维数的影响
8个信息块，母块长M=204811×2048 = 225288×2048 = 16384
p0整块删余22528−2048 = 20480删的是隐藏奇偶变量，不扣输入位
前2个信息块缩短为已知零20480−4096 = 1638416384−4096 = 12288

删余是发送时省略某些未知编码位，接收端要消去隐变量，不能随意删除任意列就当成校验；这里p0是度为1的结构，可消去对应变量和检查。缩短是把若干输入固定为已知零，并省略这些坐标。两者的维数影响不同。

公开置换在该母图中分成4个循环子块，给出 Z = M/4 = 512 的结构候选。随后程序精确检查：8条种子各在32个512位列块内同步循环移位，能生成全部4096条H行，每行都恰好14个1。这是该坐标顺序中的有效QC表示；没有证明512是唯一或最小可能的表示。

把 H 看成 8 × 32 个512方块

蓝：Hᵤ · 紫：Hₚ

每个小点代表种子在该列块内的一个循环置换项；空格为零块。不是把数千万个矩阵元素全部画成看不清的网格。滑块移动的是每个512块内的偏移，不是把整个16384位串简单平移。

一条真实校验：把14个位置的位做XOR

蓝/紫只区分信息/奇偶坐标。原始硬判决可能失败；软译码后所有检查归零。上方实验只演示一条等式，不改任何真实观测或验证结果。

05 / 从稀疏校验到生成矩阵

G不需要靠猜；H的奇偶子矩阵可逆，就能明确算出它。

把H按前K列和后N−K列分为 H = [Hᵤ | Hₚ]。这里Hᵤ为4096×12288，Hₚ为4096×4096。全程在GF(2)上计算：加法是XOR，乘法是AND，1+1=0。

Hᵤuᵀ ⊕ Hₚpᵀ = 0
pᵀ = Hₚ⁻¹ Hᵤ uᵀ
P = (Hₚ⁻¹Hᵤ)ᵀ，G = [I₁₂₂₈₈ | P]，c = uG

Python用位打包消元求完整逆；MATLAB独立检查全部8×8循环多项式的512个系数，使 Hₚ Hₚ⁻¹ = I₄₀₉₆ 精确成立。因此rank(Hₚ)=4096，rank(H)=4096，码空间维数N−rank(H)=12288；G的单位阵部分又保证rank(G)=12288，并有 GHᵀ=0。这说明G和H描述同一个条件码空间，而非只找到几条偶然成立的关系。

现在用真实输入位，亲手重建一个奇偶位

上图精确显示所选P列的12288个0/1系数，128列×96行。紫色表示该输入位参与XOR；灰色表示不参与。G通常是稠密的，H仍然稀疏。

展开所选列的系数与计算细节

浏览器从冻结模型中保存的逆矩阵首行恢复所选逆行，再与Hᵤ相乘，按需算出这一列，没有存一个伪造的示意G。输入u取自软译码后的不透明输入位；这一步是重编码一致性检查，不能包装成对未看过的奇偶观测的独立预测。

若把完整G存成double，需要约1.50 GiB，仅P就约384 MiB。这里运行时用稀疏H与QC结构表示隐式编码器，页面只算用户选中的列。精确的编码关系不要求把完整稠密矩阵展开到内存。

关键反例：偏移1个资源也能通过。QC循环等价性会造成边界歧义，所以LDPC零综合征不能单独认证“起点绝对正确”。还需CRC头部的坐标、有序分配和邻接约束。本轮没有宣称解决第一帧高阶调制边界仍相差113资源的问题。

08 / 方法对照

论文的“先G后H”，与我们本次的“先H后G”。

2026年10月29日论文，第V节讨论在候选N、K、Z和映射下，用QC循环扩充的输入/奇偶样本解 UP=V；还要检查方程一致、输入秩、未参与拟合字的奇偶预测，再找完整稀疏H，并译码、重编码、重调制。本页没有把作者其他数据上的码型结果当作本机66的既成答案。

论文给出的恢复框架

  1. 提出码字边界、位映射、N/K/Z假设。
  2. 在GF(2)上解UP=V，检查rank(U)=K。
  3. 固定P，检查拟合之外的奇偶位。
  4. 找稀疏满秩H并检查GHᵀ。

MCS 66实际采用的路线

  1. Code5与公开置换表吻合，约束候选族。
  2. 8个真实字筛选模型、缩短和位标签。
  3. 构建候选稀疏H，验证QC及Hₚ完整逆。
  4. 由H推导隐式G，再用376字进行译码检查。

为什么不能把8字写成“盲拟合出了任意G”？若暂只按8字×512种QC移位计，U最多4096行，秩上界4096，小于K=12288；而且带错硬判决不能直接当无噪声编码对。这并非本机实际完成的一次满秩UP=V恢复。我们补充的公开结构信息使未知量大幅减少；若没有这条线索，还需更多高质量样本、结构约束和专门的含噪恢复方法。

10 / 复核与阅读

什么已经证明，什么仍然没有答案。

你现在可以准确地说

在声明的资源顺序、位映射及公开结构假设下，找到了MCS66/70的接收等价QC-LDPC编码关系。固定H稀疏且满秩，能由可逆Hₚ求隐式G，真实码字经过软译码、重编码及重调制检查。

还不能直接说

已拿到官方MCS表、认证了发射机内部矩阵、确定了所有边界、测得真实BER、解密了业务内容，或证明该方法仅靠两个头部数字就能对任意新MCS奏效。

常用符号：Q、N、K、M、Z各指什么？
Q
本项目每一个长度单位占的资源数。66与70当前为4096；不要与“Q路”混淆。
N / N꜀
一个实际传输码字的比特数，当前为16384。
K / K꜀
该条件编码器的输入维数。它不是“已恢复的明文长度”。
QC
Quasi-cyclic，准循环结构，不是另一个已知长度参数。
Z
当前坐标表示下循环子块的大小512；不是整个码字长度。
M
本页公开母图的块参数2048，和Z以及MCS编号都不同。
H / G
H用于检查码字；G用于从输入生成码字。H可以很稀疏，G可以很稠密。
综合征 s
s=Hcᵀ。全零表示c满足这个H的全部校验。
