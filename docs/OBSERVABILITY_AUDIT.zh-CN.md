# 教学绘图全流程观测量审计（2026-10-28）

审计基线为 `651e339`。范围包含 `drawStep.m` 的全部实际分发、`START_HERE.m` 的22个保存步骤、`+slrx/+viz/` 的全部绘图函数及独立报告。原DSP和冻结评价器保持不变；本次修改显示、只读诊断及传递已有变量的绘图上下文。

## 1. 主线分发审计与实际处理

价值评价按当前初学者的学习目标给出，不能等同于算法性能评分。

| 原图/分发 | 原用途 | 教学价值 | 问题 | 本次实际处理 |
|---|---|---|---|---|
| case 1：原始5000点I/Q概览、单独PSD | 输入观察 | PSD高、密集波形低 | 两个图重复，波形容易被当作调制证据，DC/截幅不突出 | 合并为输入质量图：整窗分箱功率、PSD、32点离散IQ、RMS/DC/截幅；密集图移debug |
| case 2：重采样后波形 | 查看输出数组 | 低 | 即使有32点茎状图，也不能单靠波动解释250→240 MSps、FIR与DC | 替换为采样率/点数/时长、同物理时间I/Q网格、匹配物理窗PSD、原FIR频响、均值前后对比 |
| case 3：全局与局部同步 | 定位与相关依据 | 高 | 全局轨迹抽取不能当精确最大值；局部±8样本不足以估完整旁瓣或概率置信度 | 保留两个视图、精确候选事件、三坐标和选择规则；明确未保存的粗峰与置信度不能补造 |
| case 4：04/13a的2112点I前后叠加 | 观察CFO补偿 | 低 | 实部密集，不能说明复数旋转、模长不变或估计正确 | 默认彻底替换为少量复向量、累计施加角、分结构参考相位和后续EVAL说明；旧图仅debug |
| case 5：逐符号CP相关 | 复制关系概览 | 中 | 300点相关不能解释CP究竟复制哪些样本 | 主线传入已有frameTime，复用CP/尾部32对复数茎状图；标出0..31与1024..1055；旧四参数API缺上下文时明确仅有相关 |
| case 6：FFT热力图 | 频域资源概览 | 中→高 | 单独颜色不够，需要行/bin/MHz/列/导频/空载波说明 | 主线复用资源标注与坐标切换；单轮只画当前轮，诊断报告比较两轮；与单符号分解互补 |
| case 7：两张H幅度/相位 | 信道估计 | 中→高 | 缺少残差与噪声代理，容易把拟合好当独立成功 | 合并到同一信道诊断：幅相、深衰落噪声代理、已有SSS残差；均衡后可加Y/H；明确SSS残差属于训练参考 |
| case 8：只画均衡后星座 | 查看输出点云 | 中→高 | 缺少同资源均衡前数据，可能靠外观误判 | 主线同时传入本轮FFT与H，复用同行同列FFT→均衡对照；不提前运行跟踪，完整报告另比较两轮三阶段 |
| case 9：FIT相位初值与线 | 初始化 | 中 | 只有相位，没有时延或残差；FIT不等于留出验证 | 相位、时延初值与已有预览线、两种预览残差；注明ML仍使用raw初值，FIT EVM不独立 |
| case 10：候选得分/类别 | 模型分类 | 中 | K可能被误当商业MCS，类别连线可能被误读为插值 | 保留热力图、单符号柱形与分类台阶，明确K=8复合模型和业务位未知 |
| case 11：两张ML估计与拟合 | 残余同步 | 中→高 | 已保存残差、内点和代价未充分使用 | 合并为观测/拟合、残差、异常列、原代价与EVAL；代价不可跨轮直接当质量分数 |
| case 12：数值偏移更新 | 更新CFO/SFO | 数值高、重复图低 | 旧代码无默认图；重构分发必须显式保留行为 | 保留MAT/JSON数值，无额外默认图；第13轮视图展示实际采用值。首次新鲜运行暴露分发遗漏，已补回归覆盖 |
| case 14：条件硬判决 | 观测与最近点 | 中 | “最近理想点”容易被当正确业务符号 | 保留，改为条件模型最近点，显示选中符号/FFT列、有效/擦除数，导频不混入未知载荷 |
| case 15：保护窗幅度 | 模型边界排障 | 中 | 局部索引不直观，可能把预测边界叫检测结果 | 复用相对边界us、幅度/相对前窗功率；强调边界来自模型，不是静默边缘检测 |

## 2. 所有绘图函数的审查结论

| 函数 | 价值与观测量 | 处理及局限 |
|---|---|---|
| `plotCapture` | 高：输入质量 | 新默认统计量/PSD/功率/短采样，去除密集概览和原始散点 |
| `plotResampling` | 高：网格/FIR/DC | 新增并由主线/报告共同调用；只读pwelch/freqz，不重做resample |
| `plotGlobalSync` | 高：搜索范围与实际候选 | 保留；每100点轨迹不是完整峰值，精细候选事件分层 |
| `plotLocalSync` | 高：局部相关及坐标 | 保留离散茎状图；局部窗口不提供完整旁瓣或检测概率 |
| `plotCFO` | 高：运算/参考/验证分层 | 替换；独立函数 `cfoMetrics` 组织物理时间、旋转和结构内相位代理 |
| `plotSFO` | 高：时间尺度与残余时延 | 保留；初始CFO/中心频率启发式不等于独立ADC时钟真值 |
| `plotOFDM` | 高：CP/有效区/FFT索引 | 保留有目的的概览与局部离散图；一个FFT点依赖整段有效区 |
| `plotCP` | 高：32对复制样本 | 保留复数、幅度、相位与相关；高相关不是全链路证明 |
| `plotFFTGrid` | 高：资源网格 | 统一主线/报告，当前轮与两轮模式；热力图像素是离散资源，颜色不是位值 |
| `plotChannel` | 高：H、训练残差、Y/H、噪声代理 | 合并原两幅默认图，增加原SSS残差；深衰落线仅显示提示 |
| `plotConstellationStages` | 高：同轮同资源对照 | 保留统一尺度，主线均衡处仅比较当前轮FFT和均衡，独立报告含跟踪 |
| `plotPilots`（三张） | 高：EVAL EVM、点云、误差位置 | 保留原/SSS标定双约定；EVAL不参加标定；不同图分别回答多少误差/怎样扩散/坏在哪里 |
| `plotPilotFit` | 中：FIT初始化与预览残差 | 新增，替换仅相位图；不能称独立EVAL |
| `plotTracking` | 高：已有ML残差与可靠性 | 新增共享视图，合并两个旧图；不重新拟合、不修改内点 |
| `plotConditionalModels` | 中：候选模型相容性 | 保留原观测与候选理想点分离版本；不新增旋转/聚类/业务真值 |
| `plotCardinality` | 中：候选K比较 | 保留离散类别和原得分；分类是模型假设 |
| `plotFrameComparison` | 高：同类资源跨帧比较 | 保留共同可用阶段与统一尺度，标出是否逐资源配对 |
| `plotGuard` | 中：模型保护区能量 | 统一主线/报告，只读原样本，不更改预测边界 |
| `plotSampleWindow` | 低至中：高级局部数组观察 | 不再是输入/重采样默认入口，保留工具兼容与已有测试 |
| `debugPlots` | 排障工具 | 显式开关才生成旧密集波形和时域散点，独立目录，未作为质量证明 |
| `exploreRun` | 交互资源选择 | 保留帧/符号/频带/阶段选择，不改变接收值；完整CFO图内另有轮次选择 |
| `newFigure/saveFigure/teachingNotes` | 图形基础设施 | 仅控制自己创建的图窗；六项说明保存UserData，避免影响用户其他窗口 |

## 3. 默认图像的删除、替换、合并

原始历史PNG没有被删除。本次在新输出目录使用新的默认布局：

- 不再默认生成 `01_capture_iq.png` 和 `01_capture_psd.png` 两张分离图，合并为 `01_capture.png`。
- `04_frame_time.png` / `13a_frame_time.png` 文件名保留，内容替换为新的CFO解释图。
- 原 `07_channel_amplitude/phase`、`13d_channel_amplitude/phase` 合并为各一步的一张信道图。
- 原 `11_tracking_phase/delay`、`13h_tracking_phase/delay` 合并为各一步的一张跟踪图。
- 主线默认从27张减少到22张；第12步继续只记录数值。原始输入和CFO密集图仅在 `debug/` 中生成。
- 独立完整诊断从15张变为17张：额外两张是缺失的重采样物理诊断与ML残差/内点页；它们复用主线相同实现，未复制DSP。

旧文档中的27/15张是历史版本数量；现行索引见[图像阅读索引](VISUAL_DIAGNOSTICS_FIGURES.zh-CN.md)。

## 4. 仍不支持的结论

同步轨迹抽取和有限局部窗口不足以生成真实全局旁瓣比或检测概率。参考相位斜率代理仍含信道和相位混叠假设。没有保存“只关闭CFO、其余完全相同”的FFT分支，因此不存在独立的仅CFO前后EVM/ICI因果实验。EVAL只证明对应已知留出导频的误差，不能代替商业MCS、业务比特、扰码、FEC/CRC或真实业务BER/SER真值。

测试、完整新鲜接收的数值对照和未执行项目见[本轮验证](OBSERVABILITY_VALIDATION.zh-CN.md)。
