# 编号66的条件LDPC恢复与验证

2026-11-04，`pdu-receiver-v3`，实现身份 `codex_baseline`。本轮已恢复本机公开采集上**编号66的接收等价编码模型**，接入共享接收后处理和教学第20步。这里的“恢复”包含实际软译码、零校验、重编码和重调制一致性；输出仍是含义未知的编码器输入位，不能称为业务明文。

精简机器记录：[mcs66_recovery_validation.json](../provenance/mcs66_recovery_validation.json)。原始IQ、MAT、逐字译码位与浏览器HTML保留本机，不上传Git。

## 为什么选66

| 编号 | 可用码字 | 起点直接接CRC通过的第二头部 | 本轮选择依据 |
|---|---:|---:|---|
| 57 | 7 | 7 | 样本较少 |
| 66 | 376 | 117 | 样本最多；第2/3/5帧起点不依赖前置未知格式长度 |
| 70 | 91 | 0 | 起点依赖前置候选长度，先保留未知 |

其余259个66码字的起点还使用前置候选分配长度。所有数据来自同一UT Austin公开 `exemplar250-257` 采集的9个历史帧，不是9次独立采集。原始BIN SHA-256为 `c69e82022d45173cdcaf1a5fdc8a2b864e2d61e85ae819af54b16002044adae3`；下载方式见[根README](../README.md)，各协议MAT的SHA见机器记录。

## 怎样找到模型

先比较既有独立恢复的Code5稀疏H与公开AR4JA置换族，1024行的支持集合全部一致。这是一个结构线索，不是商业协议身份认证。公开数值参考为[CCSDS 131.0-B-5第7节](https://ccsds.org/Pubs/131x0b5.pdf)，数值表另与[公开实现](https://github.com/GalenMui/ccsds-ar4ja-ldpc-decoder/blob/main/models/ar4ja_matrix.py)交叉核对；没有将第三方完整接收代码复制到仓库。

只用**第2帧第1～8个66码字**选择参数。搜索131种公开置换族/整块缩短候选、216种独立I/Q线性位标签及16种极性组合。每个模型以固定随机种子1991抽128行校验，对8字计算原始硬判决校验失败比例；0.25是研究筛选线，与受保护的接收评价器门限无关。只有一种候选低于此线，比例0.14453125；筛选通过后才扩展完整4096行、求秩、验证逆并译码。未穷举所有LDPC、任意交织或非线性标签，不能宣称唯一盲恢复。

候选由8个信息块、块长2048的母图构造：未删余长度22528、输入维数16384；删余度为1的p0块2048位，缩短前两个信息块4096位。缩短按已知零输入处理，对应列删除；p0相关首组检查随隐变量消去。最终保留16384个传输坐标、12288个输入坐标。**p0删余与标准常用的p2策略不同**，所以只称“公开置换族导出的接收等价模型”。

| 参数 | 本轮结果 |
|---|---|
| 去PN后字母表 | 16QAM，平均理想功率1 |
| 每资源串行位序 | `I<0, Q<0, abs(I)<2/sqrt(10), abs(Q)<2/sqrt(10)` |
| N / K / 码率 | 16384 / 12288 / 3/4 |
| 每字Q | 4096个资源，即16384/4 |
| H / QC | 4096×16384，Z=512，8行种子，每行重14 |
| rank(H) / rank(Hp) | 4096 / 4096 |
| 信息 / 奇偶资源坐标 | 前3072 / 后1024资源 |

Q66以前来自几何与长度候选；现在有固定N、固定4位标签、完整编码关系共同支持4096。这个证据只适用于66，不能据此把70判成同一码率。信息坐标是条件编码器输入的坐标，不证明其未经上层处理。

冻结模型：[mcs66_qc512_utexas_v1.json](../matlab/protocol_receiver/models/mcs66_qc512_utexas_v1.json)，SHA-256 `183132276a399a905ac85845f5732dd38d891894415476e22b7d45bd5b792301`。其8个种子循环展开完整H；保存压缩的奇偶子矩阵逆首行。Python以GF(2)位打包消元验证完整逆，MATLAB独立核验所有8×8循环多项式乘积，证明Hp可逆与隐式生成器的GH正交。运行时使用稀疏支持与FFT循环计算，不构造16384²稠密矩阵。

## 实际验证结果

模型冻结后检查全部376字，其中368字未用于本轮参数选择。它们以前已被观测，且属于同一采集，不能称为新数据盲测。

| 1 | 39 | 39 | 4412 |
| 2 | 39 | 39 | 6588 |
| 3 | 39 | 39 | 6350 |

| 5 | 39 | 39 | 6076 |

| 8 | 53 | 53 | 9805 |

默认似然尺度0.04、归一化0.8、消息截幅±50、最多60次迭代。376字全部在2～5次迭代收敛，完整4096个校验均为0，重编码与译码字全部一致。Python与Windows MATLAB R2024b的6,160,384个码字位逐位一致。63702是译码器相对原始硬判决的改变数，缺少发送真值，不能当成真实误码数或BER。

使用相同奇偶资源，重编码16QAM重调制NMSE范围0.0268879～0.0718719；翻转奇偶位对照为2.66635～3.58844。软译码本身使用了奇偶观测，所以这是编码与观测的一致性检查，**不是未见奇偶位预测试验**。

模型单元检查另包含完整Hp逆关系、隐式GH、合成2位翻转纠正、与原通用min-sum逐位一致及位标签逆映射。既有BCC/CRC、Code5和资源分配测试通过；共享 `analyzeFrame` 的头部/Code5位与旧结果相同，关闭66分析后观测相同。

## 使用方法与输出

共享完整接收后处理默认启用66；教学第20步也调用同一函数，不增加教学图数量，完整教学仍为27张。要只补算已有 `protocol.mat`，在仓库根目录启动普通MATLAB：

```matlab
addpath('matlab/protocol_receiver')
report = RUN_MCS66_ANALYSIS( ...
    'runs/allocation-upgrade-20261103/nine_frames/frame_01/protocol.mat', ...
    'runs/my-mcs66-frame1'); % 输出目录必须全新
```

输出 `mcs66.mat` 包含 `coding.words(j).information_bits` 与 `decoded_codeword`；`mcs66_summary.json` 剔除完整位数组，保留校验、重编码、重调制和每次尝试记录，并绑定输入MAT的SHA。一般协议入口的完整结果为 `result.mcs66`。`RUN_PROTOCOL_ANALYSIS(...,'EnableMCS66',false)` 可关闭；`opt.mcs66_retry_scale=0` 可禁止备用尝试。重新运行模型测试：

```matlab
addpath('matlab/protocol_receiver','matlab/protocol_receiver/tests')
test_mcs66_receiver(pwd)
```

MATLAB批处理核验使用 `-nojvm` 及已有内存保护，只执行数值计算；普通导出入口的Java SHA与HTML/PNG导出不在本次无JVM执行范围内。376字检查约14秒，进程树私有内存峰值约1.11 GiB，宿主可用内存最低约1.70 GiB；最终集成检查约12秒、峰值约1.24 GiB、最低约1.83 GiB。预留1 GiB、MATLAB私有内存上限2 GiB，均未触发停止。这不是原始IQ全链路内存峰值，也不保证任意机器/数据不发生内存压力。
