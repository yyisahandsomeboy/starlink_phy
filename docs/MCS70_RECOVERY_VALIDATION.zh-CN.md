## 从旧失败到本次突破

旧记录中的负面实验真实有效：固定66模型、整块缩短、序列化等有限假设均未通过。后续又检验过高码率、部分QC块缩短、隐变量投影、PN/余类、分层位平面及标签假设。这些失败只排除相应有限范围。

突破是在固定传输N=16384的同时，**放开保留奇偶QC块数**，不再预设70应为7/8。沿已由Code5/66支持的公开AR4JA置换族，检查非空奇偶块子集、相应零前缀缩短及标签：255个保留子集×216种位标签×16个极性。模型选择仍只使用**旧第2帧第1～8个70单位**，每模型固定随机种子抽128行，在8字上比较硬判决校验失败比例。

胜出配置保留奇偶子块[1,2,3,4,5,6,7]，采样失败比例**104/1024=0.1015625**；相邻替代[0,2,3,4,5,6,7]为0.271484375。初筛比例仅用于研究排序，不是显著性、译码成功率或受保护评价器门限。候选选定后，再求完整逆、冻结模型并验证真实字，没有按验证结果修改H。

公开数值出处为[CCSDS 131.0-B-5第7.4节](https://ccsds.org/Pubs/131x0b5.pdf)。本机p0删余和额外删余/缩短组合不是该标准直接列出的商业MCS70配置，只称接收等价编码关系。

## 矩阵与维数

| 项目 | 恢复结果 |
|---|---|
| 调制与串行位序 | 16QAM；I<0、Q<0、abs(I)<2/√10、abs(Q)<2/√10 |
| Q / N / K / 码率 | 4096资源 / 16384位 / 12800位 / 25/32 |
| 信息/奇偶资源 | 前3200 / 后896资源 |
| H维度、H与Hp秩 | 3584×16384；rank(H)=rank(Hp)=3584 |
| QC表示 | Z512，7个种子；行重[14,14,15,27,15,15,26] |
| 未删余母图 | KB8、M2048；N22528、K16384 |
| 删余 | 整个p0的2048位，另省略p1最前512位 |
| 零缩短 | 最前3584个信息位，即7个QC512块 |

因此N=22528−2048−512−3584=16384，K=16384−3584=12800。相较66，70在同样N内多512个输入位、少512个奇偶位。额外未知奇偶变量通过GF(2)[x]/(x^512+1)中的可逆主元投影消去，不是任意删列。最后再逐行验证QC展开。

[冻结JSON模型](../matlab/protocol_receiver/models/mcs70_qc512_utexas_v1.json) SHA-256：`92823f34e239a94ec419f5a2e7d45ba86b62d3870c7be6a9478abf2e8bfb2e1d`。

H=[Hu|Hp]，由pᵀ=Hp⁻¹Hu uᵀ得到隐式生成器G=[I|(Hp⁻¹Hu)ᵀ]。Python位打包消元验证完整3584坐标的Hp逆；MATLAB独立检查所有7×7循环多项式的512个系数及GHᵀ=0。译码按行重分组，只存稀疏边消息；编码复用66中通用的QC循环计算，**模型参数和H均来自70**，没有用66矩阵代替。

## 数值结果、敏感性与反例

142字默认尺度0.04全部通过，无备用尝试；归一化系数0.8、消息截幅±50、运行时最多60次迭代，本次实际范围2～9次。合计相对初始硬判决改变25113位，**不是实际误码数或BER**。每字完整3584条检查归零；输入重编码全部等于译码字。

相同奇偶资源的重调制NMSE为0.02565716～0.06784234，翻转全部奇偶位对照为2.62813822～3.45402477。软译码已经使用这些奇偶观测，所以不能把此检查冒称为未见奇偶位的预测实验。

## 使用方法

仓库根目录的普通MATLAB：

```matlab
addpath('matlab/protocol_receiver')
report = RUN_MCS70_ANALYSIS( ...
  'runs/allocation-upgrade-20261103/nine_frames/frame_01/protocol.mat', ...
  'runs/my-mcs70-frame1'); % 必须全新输出目录
```

`mcs70.mat`保存`coding.words(j).information_bits`和`decoded_codeword`；精简JSON包含输入SHA及每字指标。一般后处理输出为`result.mcs70`；`RUN_PROTOCOL_ANALYSIS(...,'EnableMCS70',false)`可关闭。未知编号或未知前置长度仍使严格资源规划停止，不会根据星座自动补造模型。

```matlab
addpath('matlab/protocol_receiver','matlab/protocol_receiver/tests')

```
